# Naming

## Refaat

The public brand is **Refaat**. Technical and architectural material may use the acronym **REFAAT**:

- **R**etrieval
- **E**vidence
- **F**oundation for
- **A**daptive
- **A**gentic
- **T**ooling

> **REFAAT — Retrieval & Evidence Foundation for Adaptive Agentic Tooling**

The distribution, Python package, import namespace, CLI, repository, container resources, plugin entry-point groups, and environment variables use `refaat` or `REFAAT_*`.

```text
Distribution: refaat
Import:       refaat
CLI:          refaat
Environment:  REFAAT_*
Repository:   oronts/refaat
```

The name naturally carries the developer associations reference, retrieval, refinement, reflection, and reliable evidence while remaining broad enough for context, graphs, evaluations, and durable agent tooling.

The project name is not represented as completed legal trademark clearance. Perform package-name, trademark, and jurisdiction-specific review before a commercial public launch.
