# The 90-Day Production Pilot

The signature Oronts GmbH engagement is the 90-Day Production Pilot, a structured framework that takes one real use case from validation to a production system the client owns. It reflects the company promise of code you own and no vendor lock-in, and it is how Oronts delivers agentic AI, RAG, and commerce work from Munich.

## The Seven Steps

The pilot runs in seven steps: Discovery, Data and Tooling, Agentic Design, Integration, Pilot, Scale, and Governance. These compress into four phases, Validate, Build, Harden, and Scale, and each phase ends in an artifact the client keeps.

## The Day Rhythm

The engagement has a visible cadence. Repositories land in the client organization on day 1. A clickable environment is ready by day 3. A first working slice arrives in week 1. A scope checkpoint happens at day 14. The core flow runs end to end by week 6. By day 90 the system is in production, monitored and documented.

## Engineering Practices

Oronts works with pragmatic test-driven development, domain-driven design, and agile iterative delivery, with hands-on pair delivery. Documentation and architecture decision records accompany the code so a client can run and modify it without Oronts. AI-assisted development is used throughout, with senior review on everything. CI and CD carry automated quality gates, and observability and production readiness are built in rather than added later.
