# Oronts Products and Open Source

Oronts GmbH, the Munich software studio founded in 2023 by Refaat Al Ktifan, ships its own products alongside client work. Each one follows the brand promise of code you own and no vendor lock-in.

## The Oronts AI Assistant

The Oronts AI Assistant is the live agent system running on the company website. It is built on Mastra and runs five agents backed by four tools, with streaming responses and a hardened API layer. It grounds its answers and never invents prices. The assistant is the working proof of the Oronts agentic AI practice: an agent system that survives production, governed and honest about what is real.

## Vendure Customer Intelligence

Vendure Customer Intelligence is a proprietary Vendure plugin that treats wishlists, reviews, loyalty points, and cart recovery as one domain. It extends the Vendure commerce practice with retention and merchandising features engineered for ownership.

## Published open source

Two repositories are public. Vendure Data Hub, at github.com/oronts/vendure-data-hub-plugin, is an enterprise ETL and data integration plugin for Vendure. It provides a visual pipeline builder, extractors, transform operators, entity loaders, and feed generators for Google Merchant and Amazon. Pimcore Asset Pilot Bundle, at github.com/oronts/pimcore-asset-pilot-bundle, brings rule-based digital asset organization to Pimcore, with configurable rules, priority ordering, and audit logging.

## The other Oronts products

The product portfolio also includes OGuardAI, a semantic data protection runtime for AI systems that sits between an application and any LLM, and PimTx, which makes edits to Pimcore 11 and 12 safe and traceable when many people and automated jobs change the same data at once. Together with the open source plugins, these are what Oronts owns and publishes, distinct from any client build.
